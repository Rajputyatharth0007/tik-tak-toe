**🎮 Tic Tac Toe Game (Python Tkinter)**

A modern Tic Tac Toe GUI game built using Python and Tkinter,
featuring both Single Player (vs Computer) and Two Player modes with a clean,
interactive user interface.
This project focuses on GUI design, event handling, and game logic, 
making it ideal for beginners and intermediate Python learners.

✨ Features

🎯 Single Player mode (Play against Computer)
👥 Two Player mode (Player vs Player)
🧑 Player name input support
🏆 Automatic win detection
🔁 New Game option to restart instantly
❌ Exit Game button to close the application
🎨 Attractive and modern UI using Tkinter

🛠️ Technologies Used
Python 3
Tkinter (GUI Library)
